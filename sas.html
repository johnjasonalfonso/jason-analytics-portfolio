Automated File Archiving and Extraction

Technology: SAS Macro Programming, Windows Commands, WinRAR

Project Overview

This project demonstrates a reusable SAS macro solution for automating file archiving and extraction in a Windows environment. It was designed to simplify routine file-management tasks through configurable parameters and conditional logic.

Key Features

  • Archive selected files or use wildcards to select files.
  • Specify source and destination directories and archive names.
  • Support password-protected and unprotected archives.
  • Choose whether source files are deleted after archiving.
  • Extract archived files to a specified destination.

Business Value

By consolidating common archiving and extraction options into reusable macros, the solution reduces repetitive manual steps and helps standardize recurring file-management workflows.

Technical Approach

  • Parameterized SAS macros for reusability.
  • Conditional logic to control archive options.
  • Windows command execution to invoke WinRAR.

Execution requirements: A compatible Windows environment, an accessible WinRAR installation, and appropriate file-system permissions.
