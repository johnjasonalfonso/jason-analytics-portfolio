SAS & SQL Automation

A collection of automation projects demonstrating how SAS programming and SQL-based solutions can streamline recurring tasks, simplify file management, improve data preparation, and support operational reporting.

1. Automated File Archiving and Extraction

Developed reusable SAS macro routines to automate file archiving and extraction. The program supports configurable source and destination folders, archive names, file patterns, and optional deletion of source files after archiving.

Key capabilities:

  • Reusable macro-based automation.
  • Configurable input and output directories.
  • Automated file compression and extraction workflows.
  • Reduced repetitive manual file handling.

Tools: SAS Base Programming, SAS Macros, WinRAR, Windows commands.

2. Automated File Copying and Renaming

Developed a parameter-driven SAS macro to automate file copying, destination-folder creation, and file renaming. The approach makes recurring file-transfer tasks more consistent and reduces repetitive manual intervention.

Key capabilities:

  • Reusable macro parameters for source and destination paths.
  • Configurable original and new filenames.
  • Automated destination-folder creation.
  • Standardized recurring file-management tasks.

Tools: SAS Base Programming, SAS Macros, Windows commands.

3. Automated Download-File Cleanup

Created a configurable SAS cleanup template for identifying and managing selected files in designated directories. The workflow demonstrates how recurring file-cleanup activities can be standardized before downstream data-processing tasks.

Key capabilities:

  • Configurable directory and file-type filters.
  • Identification of selected BCP, TXT, and CSV files.
  • File counts and execution logging.
  • Dry-run mode to review potential deletions before execution.

Tools: SAS Base Programming, SAS Macros, file-system commands.
